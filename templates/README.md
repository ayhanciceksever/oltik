# Teslim şablonları

Yeni bir müşteri işi için:

```bash
cp -r templates engagements/<musteri-kodu>
```

`engagements/<musteri-kodu>/` yereldir ve commit edilmez. Şablon iyileştirmeleri yalnız bu klasörde yapılır (görev 6.2).

| Klasör | Kullanım | Görev |
|---|---|---|
| [proposal/](proposal/) | A ve B teklifleri | 2.5, 3.3 |
| [audit/](audit/) | AI Audit karar paketi | 4.2–4.4 |
| [implementation/](implementation/) | Pilot / kurulum | 5.1–5.3 |
| [data/](data/) | Veri kabulü ve kapanış | 2.2, 4.1 |
| [records/](records/) | Asgari iş kaydı şeması | 7.3, 8.1 |
