# SENTETİK ÖRNEK · Müşteri cevabı taslağı (görev 2.4)

> **Bu klasör tamamen sentetiktir.** Gerçek müşteri, gerçek sonuç veya referans değildir; satışta başarı vakası olarak kullanılmaz.

**Hayalî işletme:** “Örnek Perakende” — e-ticaret kanalı olan bir perakendeci.
**İş akışı:** Müşteri e-postalarına kaynak gösteren cevap taslağı; insan kontrol edip gönderir.
**Kapsam dışı:** AI'ın fiyat, stok, teslimat, indirim, iade veya ödeme taahhüdü vermesi.

Doldurulacak dosyalar `templates/audit/` şablonlarından kopyalanır. Amaç: teklifin çıktısını alıcıya göstermek ve kalite kontrol listesini sınamak.

- [ ] Süreç haritası
- [ ] Kanıt kartı (sentetik sayılar `bilinmiyor` / `sentetik` notuyla)
- [ ] Seçenek kartı (AI dışı seçenek ve “yatırım yapma” dahil)
- [ ] Ekonomi dosyası (olumsuz senaryo dahil)
- [ ] Karar özeti
- [ ] Pilot şartnamesi
- [ ] Çıkarı olmayan yetkin inceleyen okuması
